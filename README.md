# Rizky Rinaldi Website

Website portfolio dan blog profesional untuk Rizky Rinaldi, S.Kom., M.Kom.

## Tech Stack
- Astro 7.0.7 (Static Site Generator)
- Tailwind CSS
- Pagefind (Client-side Search)
- Cloudflare Pages (Deployment)

## Development
```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
